Welcome to pyLightspeed's documentation!
========================================

**pyLightspeed** is a wrapper for Lightspeed's various series so that the apis can be called in a consistent way. Based on the BigCommerce API wrapper, it provides dot notation access
 to the various resources/endpoints to make scripting and moving data around easier.

 Check out the :doc:`usage` section for further information.

.. note::

   This project is under active development. The code is terrible. It's not tested. Good luck.
